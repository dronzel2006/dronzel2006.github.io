Как подключить к сайту

Одна строчка в обработчике формы.

// отправка формы на сервер бота
fetch('https://ваш-сервер/lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name, phone, message, source: location.hostname })
});
